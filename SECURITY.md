# Security Policy

## Supported versions

Security fixes currently target the latest source revision and the latest
published release.

## Reporting a vulnerability

Please use GitHub's private security advisory feature instead of opening a
public issue. Include the affected Android version, LSPosed version, target
package, reproduction steps, and whether the Camera Intent Probe reproduces
the problem.

Do not include private application data, selected images, access tokens,
keystores, or logs containing sensitive URI contents.

## Intended use

This project is intended for learning, development, accessibility, and testing
on devices and applications you own or are authorized to assess. It does not
attempt to bypass Camera1, Camera2, CameraX, biometric liveness checks, or
custom camera SDKs.
